# Convite web — Primeiro aniversário do Bernardo

## Como visualizar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie a pasta inteira para uma hospedagem estática (por exemplo, Netlify ou GitHub Pages).

## Personalizações pendentes
- **Foto:** coloque a foto principal em `assets/foto-bernardo.jpg`. Mantenha esse nome. A área de abertura da segunda tela já está preparada.
- **Localização:** abra `script.js` e preencha `locationUrl` com o link compartilhável do Google Maps.
- **Medidas:** edite os três campos `A preencher` em `index.html`.
- **Pix:** coloque o QR Code como imagem na área Pix e informe a chave em `CONFIG.pixKey` no `script.js`. O botão de copiar será habilitado automaticamente.
- **WhatsApp:** o número informado já está configurado com DDI 55 e mensagem pronta.

## Arquivos
- `index.html` — estrutura do convite e modal.
- `style.css` — identidade visual, layout responsivo e animações.
- `script.js` — abertura, WhatsApp, localização e modal.
- `assets/envelope-bernardo.jpg` — imagem enviada, recortada para encaixar melhor na abertura.

O convite está preparado para celular e desktop. A foto, localização, medidas e dados Pix ainda são espaços reservados porque esses dados não foram enviados.
